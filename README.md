# little frames 📸

A browser photobooth. Open it, strike four poses, and get an aesthetic photo strip to download.

**Live demo:** https://namanagr26.github.io/little-frames

## Features
- Live camera preview with a countdown, flash and shutter sound
- 19 filters: B&W, Silver, Cocoa, Velvet, Film, Noir, Vintage, Dreamy and more
- 14 frame themes: Contact, Velvet, Lace, Walnut, Classic, Film negative, Y2K, Gazette, Kraft and more
- Layouts: strip ×4 / ×3, duo, 2×2 grid, 2×3 grid, double strip
- Wide or tall photos, captions, date stamp, stickers
- Retake any single shot, and the strip re-renders when you change the style
- Download the strip as a PNG, or as a flipbook video (MP4/WebM)
- Works with photos from your device if you don't want to use the camera

## Privacy
Everything runs in your browser. No photos are uploaded anywhere.

## Run locally
Open `index.html` in Chrome, Edge or Safari. The camera needs `https` or a local file, and GitHub Pages serves over https.

## Deploy on GitHub Pages
1. Push this repo to GitHub
2. Go to Settings → Pages → Branch: `main`, folder `/ (root)` → Save
3. Your site appears at `https://YOUR-USERNAME.github.io/little-frames`
